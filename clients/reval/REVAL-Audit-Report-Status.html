1) نظرة عامة

  • الموقع ثنائي اللغة (عربي + إنجليزي)، مبني على WordPress + Astra + Elementor، وبه 16 صفحة (8 عربي + 8 إنجليزي).
  • الصفحات: الرئيسية، من نحن، خدماتنا، لماذا رفال، القطاعات، HSE والاستدامة، اتصل بنا، انضم إلينا.

الملاحظات وحالة المعالجة

✓ تم 1- بيانات الدخول والاستضافة: تم شراء الاستضافة واستلام بيانات السيرفر (SSH) ولوحة الاستضافة (cPanel).
✓ تم 2- حساب الدومين: تم شراء الدومين.
✓ تم 3- حظر الفهرسة (noindex): رُفع حظر الفهرسة عن جميع الصفحات الـ16 وأصبح الموقع قابلاً للظهور في محركات البحث.
✓ تم 4- خريطة الموقع والـ robots.txt: تم إنشاء ملف Sitemap.xml وملف robots.txt وربطهما بالموقع.
✓ تم 5- الميتا وOpen Graph وSchema: تم تركيب إضافة SEO (Yoast) وتُولَّد الآن أوصاف الميتا ووسوم المشاركة والبيانات المنظمة تلقائياً.
⏳ لم يتم بعد 6- التحليلات والتتبع: بانتظار رقم Google Analytics (GA4) منكم لإضافته.
✓ تم 7- الأزرار والنماذج المعطلة: أُصلح زر "شاهد الوظائف"، وأُصلح رفع السيرة الذاتية ليقبل PDF وWord، وصُحّحت أسماء حقول النموذج (تكرار حقل الجوال) بحيث تصلكم البيانات على بريد الشركة.
✓ تم 8- خريطة صفحة اتصل بنا: استُبدلت الخريطة الخاطئة بموقعكم الصحيح.
✓ تم 9- رابط صفحة انضم إلينا بالعربي: أصبح الرابط نظيفاً بالإنجليزية: reval-sa.com/ar/join-us/
✓ تم 10- عنوان تبويب المتصفح للصفحة العربية: أصبح العنوان بالعربية: "ريفال لإدارة العمليات".
⏳ لم يتم بعد 11- حماية CAPTCHA للنماذج: بانتظار اختيار مزوّد الحماية وتزويدنا بالمفاتيح اللازمة.
✓ تم 12- حماية تخمين كلمة المرور: تم تفعيل حماية من محاولات الدخول المتكررة (Limit Login Attempts).
ملاحظة: الموقع يعمل على النطاق reval-sa.com (وليس revalksa.com كما ورد سابقاً).
